# dotfiles

## Pre-requisites

```
zsh zsh-autosuggestions zsh-syntax-highlight
```

On Debian:

```shell
chsh /bin/zsh
```

## Installation

```shell
git clone git@github.com:alexeydonov/dotfiles.git ~/.dotfiles
~/.dotfiles/install
```

To use color prompt:

```shell
echo emerald|lemon|frost|fire|sand|barbie|mono|root >~/.prompt
```
